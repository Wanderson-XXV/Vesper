# Handoff rápido para um novo agente

Se outro agente receber o repositório e precisar trabalhar sem contexto da conversa, envie esta instrução junto:

> Leia primeiro `docs/00_INDEX.md`, `01_DESIGN_BIBLE.md`, `02_NARRATIVE_BIBLE.md`, `03_UI_UX_BIBLE.md`, `04_RITUAL_PEDAGOGY.md`, `05_CONTENT_ARCHITECTURE.md`, `09_LEARNING_TRACKS.md` e `10_AUTHORING_WORKFLOW.md`. Depois leia o Authoring Pack v1.2. Não edite código da engine para resolver um problema que pode ser corrigido em conteúdo. Antes de alterar uma cena, identifique qual learning track está ativa e quais flags controlam o contexto. Preserve a progressão pedagógica e o setting gótico/vitoriano.

## Para roteiro
Use `prompts/01_EDIT_SCENE.md` ou `02_DIALOGUE_POLISH.md`.

## Para a rota de if/else
Use `prompts/04_CREATE_IF_ELSE_TRACK.md` junto de `specs/IF_ELSE_TRACK.md`.

## Para novo exercício
Use `prompts/03_CREATE_RITUAL.md`.

## Para documentação de estudo
Use `prompts/05_GRIMOIRE_ENTRY.md`.
