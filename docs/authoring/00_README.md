# Mansão de Vesper — Authoring Pack v1.2

Este pacote existe para permitir que o projeto continue fora da conversa original sem depender da memória do chat.

## O que há aqui

- `specs/V6_SPEC.md`: escopo concreto da próxima versão.
- `specs/IF_ELSE_TRACK.md`: rota pedagógica proposta para alunos iniciando `if` / `else`.
- `specs/WRITING_RULES.md`: regras rápidas de roteiro e diálogo.
- `prompts/`: prompts prontos para delegar tarefas a outro agente.
- `templates/`: modelos de cena, ritual, personagem, evidência e entrada de grimório.
- `assets/reference/exterior_portao_fechado.png`: background aprovado para o exterior antes do Ritual 0.

## Como usar com outra IA

Envie primeiro, nesta ordem:

1. `01_DESIGN_BIBLE.md` do repositório principal.
2. `02_NARRATIVE_BIBLE.md`.
3. `04_RITUAL_PEDAGOGY.md`.
4. `05_CONTENT_ARCHITECTURE.md`.
5. O prompt específico deste pacote.
6. Somente os arquivos de conteúdo que aquela tarefa precisa alterar.

Não peça “melhore tudo”. Dê uma unidade de trabalho: uma cena, um NPC, um ritual ou uma track.

## Regra de ouro

A fantasia é a camada de significado; o conteúdo pedagógico é a estrutura. Nenhum dos dois deve parecer colado por cima do outro.
