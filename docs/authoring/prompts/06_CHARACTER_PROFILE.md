# Prompt — criar/editar perfil de personagem

Crie a ficha de Arquivo para `[PERSONAGEM]`.

Separe estritamente:
- verdade interna do roteiro;
- informação atualmente conhecida pelo jogador.

A UI de perfil só pode exibir a segunda categoria.

Campos:
- nome;
- papel conhecido;
- primeira impressão da protagonista;
- o que sabemos;
- última observação;
- evidências relacionadas;
- tópicos de conversa desbloqueados;
- condições para novas notas aparecerem.

Evite texto omnisciente. A ficha é escrita do ponto de vista da investigação.
