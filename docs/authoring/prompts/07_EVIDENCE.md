# Prompt — criar evidência

Crie uma evidência investigativa para `[FUNCAO_NARRATIVA]`.

Ela precisa:
- existir fisicamente no setting;
- poder ser encontrada numa cena concreta;
- revelar uma coisa e, se possível, levantar outra pergunta;
- ter uma versão visual reabrível no Arquivo de Campo;
- evitar explicar diretamente algo que poderia ser inferido.

Entregue:
- id;
- título;
- tipo;
- local de descoberta;
- visual original/documento;
- resumo de arquivo;
- personagens ligados;
- flags desbloqueadas;
- assunto de conversa que ela habilita;
- JSON sugerido.
