# Prompt — desenvolver a rota if/else

Use `specs/IF_ELSE_TRACK.md` como especificação inicial e transforme-a em conteúdo jogável.

A track é destinada a alunos iniciantes em Java que conhecem ou estão aprendendo:
- variáveis simples;
- comparações;
- `if`;
- `if / else`;
- `else if`;
- `&&` e/ou `||` somente depois de condicionais simples.

Não exigir arrays ou loops como solução principal.

Para cada slot `gate`, `hall`, `gallery`, `bedroom`, `office`, `basement`:
- escreva a cena curta que introduz a situação;
- faça Tomás explicar o fenômeno sem entregar o código;
- faça a protagonista reformular o que precisa decidir;
- crie/ajuste o challenge JSON;
- crie 2–3 dicas progressivas;
- defina qual entrada de Grimório deve estar desbloqueada;
- preserve as consequências narrativas principais da campanha;
- liste quais diálogos opcionais precisam mudar porque a track usa fenômenos diferentes.

No final, entregue:
1. mapa da progressão pedagógica;
2. cenas novas/alteradas;
3. challenges;
4. mudanças de flags;
5. checklist de teste com aluno iniciante.
