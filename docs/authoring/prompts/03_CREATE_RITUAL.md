# Prompt — criar um ritual

Crie um ritual para a learning track `[TRACK]` no slot narrativo `[SLOT]`.

Conceito pedagógico obrigatório:
`[CONCEITO]`

Pré-requisitos que o aluno já conhece:
`[PRE_REQUISITOS]`

A cena ocorre em:
`[LOCAL]`

Pista/consequência que o rito precisa produzir:
`[CONSEQUENCIA]`

O rito deve conter:
1. situação ficcional concreta;
2. motivo para resolver agora;
3. significado físico/ritual de cada entrada;
4. resultado que o personagem realmente precisa;
5. reformulação do problema pela protagonista;
6. enunciado curto da HUD;
7. exemplo de entrada e saída;
8. 2 ou 3 dicas progressivas de Tomás;
9. consequência narrativa do acerto;
10. uma entrada correspondente de Grimório ou referência a uma existente.

Não use arrays/loops se a track não permitir. Não use números apenas porque “precisamos de números”: cada valor deve representar algo no mundo.
