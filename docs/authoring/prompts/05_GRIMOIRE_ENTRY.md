# Prompt — criar/expandir verbete do Grimório

Crie um verbete do Grimório sobre `[TEMA]` para aluno iniciante em Java.

O Grimório é um caderno antigo usado pela protagonista. Ele deve ensinar de verdade, mas não soar como landing page, documentação corporativa ou interface cyberpunk.

Estrutura:
- título diegético + termo Java;
- anotação curta da protagonista;
- O que é;
- Como pensar;
- Forma em Java;
- Exemplo pequeno;
- Erro comum;
- Quando isso aparece num rito;
- dica opcional de Tomás.

Explique com clareza suficiente para o aluno consultar sozinho durante um exercício. Não presuma que ele conhece termos técnicos não apresentados.
