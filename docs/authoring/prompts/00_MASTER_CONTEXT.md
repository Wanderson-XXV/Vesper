# Prompt-mestre para outro agente

Você vai trabalhar em um projeto chamado **A Mansão de Vesper**.

É uma visual novel web educacional de investigação sobrenatural em fantasia gótica/vitoriana. A referência principal de sensação de interface e presença dos personagens é *No, I’m Not a Human*, sem copiar seus assets ou sua história.

A programação existe dentro do mundo como **rituais**: o jogador interpreta leituras, escreve Java fora do jogo, obtém uma resposta e a devolve à interface. A resposta precisa provocar uma consequência narrativa.

Regras essenciais:
- não usar celulares, mensagens instantâneas ou estética cyberpunk;
- Tomás Vale é mentor de campo: econômico, experiente, claro quando precisa orientar;
- NPCs nunca devem soar como documentação técnica;
- perguntas de conversa só aparecem se aquele assunto já foi apresentado;
- a narração descreve observáveis e evita resolver o mistério pelo jogador;
- rituais precisam ter contexto, risco, significado dos dados e objetivo antes da HUD abrir;
- não criar metacomentários do tipo “este exercício é fácil de propósito”;
- não alterar arquitetura/JSON fora do escopo sem explicar antes por que é necessário;
- preservar a progressão pedagógica definida pela learning track ativa.

Antes de produzir qualquer alteração, leia as bíblias do projeto e identifique quais arquivos de conteúdo realmente precisam mudar.
