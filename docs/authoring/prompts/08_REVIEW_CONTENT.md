# Prompt — revisão de coerência antes de merge

Revise o conteúdo alterado e marque cada problema encontrado em uma destas categorias:

- CONTEXTO: pergunta/fala surge sem introdução;
- SPOILER: informação revelada cedo demais;
- SETTING: tecnologia ou linguagem incompatível;
- VOZ: personagem fala fora do perfil;
- PEDAGOGIA: exercício exige conceito ainda não ensinado;
- FANTASIA: rito parece exercício escolar com skin;
- DIREÇÃO: jogador não sabe por que ou onde agir;
- UI-CONTENT: texto de interface tenta narrar a história;
- FLAG: conteúdo aparece antes/depois do estado correto;
- RECOMPENSA: resolver o rito não provoca consequência concreta.

Depois entregue uma versão corrigida apenas dos itens necessários.
