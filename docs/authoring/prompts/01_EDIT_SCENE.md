# Prompt — editar uma cena

Use o prompt-mestre e as bíblias do projeto.

Tarefa: reescrever a cena `[SCENE_ID]`.

Objetivo narrativo da cena:
`[OBJETIVO_NARRATIVO]`

Conhecimento que o jogador possui antes da cena:
`[CONHECIMENTO_PREVIO]`

Informações que esta cena PODE revelar:
`[PODE_REVELAR]`

Informações que esta cena NÃO PODE revelar ainda:
`[NAO_REVELAR]`

Função pedagógica, se houver:
`[FUNCAO_PEDAGOGICA]`

Requisitos:
- garantir que cada fala tenha contexto;
- cortar exposição substituível por ação, pista ou documento;
- Tomás deve ser conciso sem ficar criptográfico;
- qualquer pergunta desbloqueada depois deve ter assunto apresentado nesta ou em cena anterior;
- se houver ritual, terminar com a protagonista reformulando claramente o problema.

Entregue:
1. cena revisada;
2. lista de flags/requisitos usados;
3. tópicos de conversa que esta cena pode desbloquear;
4. observações sobre continuidade;
5. JSON pronto para substituir a cena, se o esquema estiver disponível.
