# Kit portátil de autoria — Vesper 1.0

Este diretório pode ser entregue a outra IA ou pessoa sem histórico de chat. O repositório continua sendo a fonte de verdade; a saída externa só entra no jogo depois de validação e revisão humana.

## Enviar junto

1. `MASTER_CONTEXT.md`;
2. `CASE_BRIEF.template.md` preenchido;
3. `RITUAL_CONTRACT.template.json` para cada rito;
4. documentos da rota em `docs/pedagogy/`;
5. fichas canônicas necessárias em `docs/canon/`;
6. `DELIVERY_CONTRACT.md`.

## Ordem de produção

1. público, pré-requisitos, objetivo e duração;
2. pergunta central, resposta, gancho, evidências e escolhas;
3. locais, personagens e conexões;
4. slots de ritual e consequências;
5. progressão pedagógica;
6. cenas específicas por rota quando a natureza dos dados muda;
7. variantes de linguagem;
8. pacote de entrega;
9. importação, `npm run validate` e playtest.

## Regra de importação

Nunca colar uma resposta externa diretamente sobre conteúdo jogável. Importe para um diretório de caso novo, verifique IDs/referências, leia as cenas adjacentes e só então registre no catálogo.
