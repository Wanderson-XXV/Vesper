# Regras de escrita — Mansão de Vesper

## Tom
Fantasia gótica/vitoriana, investigação sobrenatural, estranheza gradual.

## Tecnologia
Não usar celular, mensagem instantânea, tela digital moderna ou linguagem de software como elemento diegético. Instrumentos podem ser mecânicos, ritualísticos, óticos, químicos ou eletromecânicos compatíveis com a estética escolhida.

## Diálogo
- Personagens falam como pessoas, não como documentação.
- Tomás é direto, mas compreensível.
- Uma fala curta só funciona se o contexto já estiver claro.
- Perguntas de conversa só aparecem depois de o assunto ter sido introduzido.
- Evitar exposição que o jogador pode descobrir por documento, ambiente ou contradição.
- Evitar frases que descrevem a intenção do design: “isso é fácil”, “este é o tutorial”, “agora você aprendeu”.

## Narração
- Descrever observáveis.
- Não concluir pelo jogador quando a conclusão é parte do mistério.
- Preferir detalhes concretos a adjetivos genéricos de terror.

## Rituais
Antes da HUD abrir, a cena deve responder:
1. O que está acontecendo?
2. Por que isso importa agora?
3. O que os dados representam no mundo?
4. Qual resposta precisamos obter?

A protagonista deve reformular a tarefa em linguagem simples quando isso ajudar o aluno.

## Recompensa
O resultado do programa deve causar uma consequência no mundo: abrir, separar, revelar, classificar, reconstruir, escolher, impedir ou confirmar algo.
