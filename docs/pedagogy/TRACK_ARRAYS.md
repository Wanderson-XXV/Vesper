# Track — arrays_beginner

## Público
Aluno começando lógica com arrays, `for`, `if`, comparação e variáveis de estado.

## Regra de progressão
Cada rito deve reaproveitar algo anterior e introduzir no máximo um salto mental principal.

| Slot | Conceito principal | Intenção pedagógica |
|---|---|---|
| gate | tutorial de leitura/contagem | aprender o loop do jogo, não testar dificuldade |
| hall | array + `for` + `if` + contador | percorrer e decidir |
| gallery | atual vs anterior | comparar presente com passado |
| bedroom | estado/reset | manter memória durante o percurso |
| office | máximo | guardar o melhor valor observado |
| basement | consecutivos | combinar comparação + estado + máximo |

## Princípios
- o primeiro rito pode ser resolvido no olho; ele ensina o fluxo da interface;
- o primeiro desafio real ainda deve ser curto;
- dados maiores entram quando escrever código já é claramente mais conveniente;
- Tomás ajuda mais no início e menos no fim;
- o boss não deve introduzir uma nova ferramenta lógica; deve combinar as anteriores.

## Critério de qualidade
Antes de codar, o aluno deve conseguir dizer em português o que o programa precisa fazer.
