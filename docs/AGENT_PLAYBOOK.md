# Agent Playbook — prompts curtos

O repo contém contexto suficiente para prompts curtos. Prefira pedir objetivo e deixar o roteamento trabalhar.

## Script doctor
> Faça uma auditoria do roteiro do Caso 01 usando `vesper-narrative`. Liste CRITICAL/IMPORTANT/POLISH antes de alterar. Pare para aprovação antes de uma reescrita ampla.

## Uma cena
> Revise `scene_id`. Leia a cena anterior e posterior, preserve IDs e função pedagógica. Mostre diagnóstico e proposta antes de editar se a mudança for grande.

## Track if/else
> Termine `conditionals_beginner` como track jogável. Use `vesper-ritual-design`, depois `vesper-narrative`. Não altere `arrays_beginner`. Rode validação completa e registre changelog.
