# A Mansão de Vesper — documentação-base v1.1 / V5

Esta pasta é a **fonte de verdade do projeto**. A conversa pode mudar, o código pode crescer e a campanha pode receber novas versões, mas decisões estruturais devem primeiro ser refletidas aqui.

## Ordem recomendada de leitura

1. `01_DESIGN_BIBLE.md` — o que o jogo é e o que ele não é.
2. `02_NARRATIVE_BIBLE.md` — tom, cenário, personagens, regras de roteiro e canon do Caso 01.
3. `03_UI_UX_BIBLE.md` — linguagem visual, retratos, caixas de diálogo, documentos, inventário e Grimório.
4. `04_RITUAL_PEDAGOGY.md` — como transformar conteúdo de programação em rituais e como construir progressão de dificuldade.
5. `05_CONTENT_ARCHITECTURE.md` — como a campanha deve ser organizada em JSON e quais dados pertencem a cada arquivo.
6. `06_REPO_MAP.md` — onde encontrar e editar cada coisa no repositório.
7. `07_AI_AUTHORING_PROMPTS.md` — prompts-base para pedir alterações a outra IA sem perder a direção do projeto.
8. `08_V5_BACKLOG.md` — registro das correções implementadas na V5.
9. `09_LEARNING_TRACKS.md` — como trocar a progressão pedagógica sem duplicar a história.
10. `10_AUTHORING_WORKFLOW.md` — rotina prática para continuar o projeto em outro chat/IA.

## Princípio central

> **A Mansão de Vesper é uma aventura de investigação e horror em que programação é uma ferramenta diegética. Não é uma lista de exercícios coberta por uma skin de terror.**

Toda decisão de conteúdo deve preservar isso.
