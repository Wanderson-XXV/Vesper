# Feedback Promotion Checklist

Antes de transformar feedback em regra permanente:

- [ ] isso apareceu mais de uma vez ou o usuário disse explicitamente que é regra daqui para frente?
- [ ] é uma preferência global, não só desta cena?
- [ ] já existe regra equivalente em outra bíblia?
- [ ] a nova regra conflita com alguma decisão existente?
- [ ] sabemos onde ela deve morar?

Destino:
- escrita/personagem -> `docs/canon/`;
- visual -> `docs/art/`;
- currículo -> `docs/pedagogy/`;
- arquitetura/canon grande -> `docs/decisions/`.
