# Feedback Memory

Objetivo: fazer a equipe de agentes melhorar conforme o diretor do projeto corrige resultados.

## Inbox
Feedback recente ainda não classificado.

## Accepted
Feedback considerado reaproveitável. Deve registrar o problema, a regra aprendida e onde ela foi promovida.

## Promotion
Se o feedback for permanente:
- voz/roteiro -> `canon/WRITING_RULES.md` ou `CHARACTER_BIBLE.md`;
- setting -> `canon/WORLD_RULES.md`;
- visual -> `art/ART_DIRECTION.md`;
- pedagogia -> `pedagogy/RITUAL_PEDAGOGY.md`/track;
- arquitetura -> `decisions/` + docs de arquitetura.

Feedback local de uma única cena não precisa virar lei global.
