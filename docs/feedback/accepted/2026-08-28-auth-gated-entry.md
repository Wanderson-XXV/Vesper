# Feedback consolidado — entrada por conta e identidade única

## Classificação

Decisão de produto e regra reutilizável de onboarding.

## Aprendizados promovidos

- a conta não deve competir visualmente com as ações do caso; o acesso pertence ao canto do Hub;
- iniciar ou retomar investigação exige sessão autenticada;
- login é a primeira tela de autenticação; cadastro aparece por escolha explícita;
- no MVP, usuário é a identificação do investigador e não deve haver campo duplicado de nome;
- privilégios de mentor não pertencem ao cadastro público; a decisão posterior `0012` tornou obrigatório o código de equipe para estudantes;
- criação de personagem será uma camada futura do perfil, separada da autenticação.
