# 0007 — Feedback vira memória do projeto

## Decisão
Correções reutilizáveis do usuário devem ser consolidadas no repo.

## Motivo
A visão do projeto não pode depender de uma thread longa de chat.

## Consequência
Usar `docs/feedback/` e a skill `vesper-feedback-consolidation`; promover regras úteis para bíblias/decisions.
