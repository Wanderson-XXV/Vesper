# 0008 — Vesper é uma antologia multicase

## Decisão

**Vesper** é o produto e universo. **A Mansão de Vesper** é o Caso 01. Casos podem ser independentes pedagogicamente e compartilhar investigador, personagens recorrentes e metamistério.

## Consequência

Conteúdo segue `universo → caso → rota curricular → variante de linguagem`. Estado local de caso não vaza para outro; somente fatos declarados como `carryForward` entram no perfil global.
