# 0003 — Learning tracks independentes

## Decisão
A mesma mansão pode usar currículos diferentes por meio de slots de rito e cena.

## Motivo
Permitir versões para arrays, if/else e futuros conteúdos sem duplicar toda a aventura.

## Consequência
Alterar `conditionals_beginner` não deve quebrar `arrays_beginner`. Cenas de introdução podem ser específicas da track.
