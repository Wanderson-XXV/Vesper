# 0004 — Perfis dependem de descoberta

## Decisão
Personagens não aparecem automaticamente no Arquivo só por existirem em `characters.json`.

## Motivo
Theo apareceu cedo demais no protótipo e gerou spoiler/contradição visual.

## Consequência
Usar `knownCharacters`, `revealWhen` e flags para controlar perfis visíveis.
