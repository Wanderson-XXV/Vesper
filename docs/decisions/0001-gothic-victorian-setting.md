# 0001 — Setting gótico/vitoriano

## Decisão
Vesper usa um mundo ficcional de estética vitoriana/edwardiana tardia, sem tecnologia cotidiana contemporânea.

## Motivo
Celular, UI futurista e conveniências modernas quebraram a imersão durante o protótipo.

## Consequência
Telegramas, cartas, instrumentos mecânicos e dispositivos ritualísticos substituem equivalentes modernos.
