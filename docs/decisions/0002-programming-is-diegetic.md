# 0002 — Programação é diegética

## Decisão
O aluno escreve Java, mas o personagem está formalizando um ritual no mundo.

## Motivo
Evitar “exercício escolar com skin” e integrar aprendizagem à investigação.

## Consequência
NPCs explicam fenômenos, instrumentos e decisões; não falam “array”, “tutorial” ou “esse exercício é fácil” como designers do jogo.
