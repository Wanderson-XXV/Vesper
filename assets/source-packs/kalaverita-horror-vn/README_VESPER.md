# Kalaverita Visual Novel Horror Asset Pack — mapa para agentes

Este diretório preserva o pack completo para que agentes possam experimentar novas expressões, sprites, props e UI sem depender do histórico de chat.

## Famílias principais
- `BUTLER_FULL1..4` / `BUTLER_FACE1..16` — base mais associada a Tomás Vale no protótipo;
- `GIRL_FULL1..16` / `GIRL_FACE1..64` — grande variedade de estados/expressões; material candidato;
- `MAID_FULL1..4` / `MAID_FACE1..20` — material candidato para NPCs futuros;
- `NURSE_FULL1..4` / `NURSE_FACE1..16` — material candidato para NPCs futuros;
- `PROP1..17` — props;
- `ROOM*` — backgrounds do pack, não necessariamente canônicos.

## Regra
Não trocar personagem de produção automaticamente só porque há uma expressão melhor. Primeiro proponha o asset e confira coerência narrativa/visual.
