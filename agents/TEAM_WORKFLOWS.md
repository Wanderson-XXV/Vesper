# Team Workflows

## 1. Melhorar uma cena existente
**Director -> Narrative -> Reviewer -> Feedback consolidation**

Prompt inicial sugerido:
> Revise a cena `<id>`. Faça auditoria antes de editar. Preserve função pedagógica e canon. Use as skills/roteamento do repo.

## 2. Criar/terminar a track de if/else
**Director -> Pedagogy -> Narrative -> Implementer -> Reviewer -> usuário testa -> Feedback consolidation**

Pedagogy fecha regras/inputs/outputs primeiro. Narrative escreve contexto depois. Não inverter isso.

## 3. Mudar UI de uma tela
**Director -> Art Director -> Implementer -> Reviewer**

Sempre fornecer screenshot quando houver problema visual observável.

## 4. Criar novo capítulo
**Director -> Narrative (outline) + Pedagogy (slots) -> Art Director (asset needs) -> Implementer -> Reviewer**

Não começar escrevendo 40 cenas antes de central question, payoff e slots estarem definidos.

## 5. Incorporar feedback do usuário
**Feedback consolidation** classifica local/reutilizável/canon. Só depois atualiza bíblias.

## Regra de handoff
Cada agente termina com:
- o que mudou;
- o que deliberadamente não mudou;
- arquivos tocados;
- riscos/pendências;
- testes executados;
- recomendação para o próximo papel.
